# Sales & Order Management Analytics

A data analytics project that analyzes sales and order-management data using MySQL and Power BI.

## 📌 Project Overview

This project analyzes transactional data to understand:

- Sales and revenue performance
- Order performance and status
- Product and category performance
- Customer contribution
- City-level sales performance
- Repeat customers
- Payment performance
- Inventory information

SQL is used for data preparation and business analysis, while Power BI is used to create an interactive dashboard.

## 🛠️ Tools Used

- MySQL
- Power BI
- SQL

## 🗂️ Database Structure

The project contains five main tables:

| Table | Purpose |
|---|---|
| customers | Customer details and customer-level analysis |
| products | Product, category, price and inventory information |
| orders | Order date, customer, status and order amount |
| order_items | Products and quantities included in each order |
| payments | Payment amount, date and payment status |
